# Space Runner - Phaser 3 Mobile Game

A space shooter game built with Phaser 3 game engine.

## How to Play

- **Tap left side** - Move left
- **Tap right side** - Move right
- **Tap center** - Shoot
- **Arrow keys + Space** - Desktop controls

## Features

- Phaser 3 arcade physics
- Touch and keyboard controls
- Particle effects
- Progressive difficulty
- High score saving

## Run

Open `index.html` in a browser.
